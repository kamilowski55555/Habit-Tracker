# Habit-Tracker

## 🎓 Bachelor Thesis Project

A full-stack web application for tracking daily habits and building positive routines.

## 📖 Overview

Habit-Tracker is a personal habit management system that allows users to create, monitor, and maintain their daily habits. The application provides an intuitive interface for habit tracking, progress monitoring, and includes an AI-powered chatbot for personalized assistance.

## ✨ Features

- **User Authentication** - Secure login and registration with JWT
- **Habit Management** - Create, edit, and delete habits
- **Progress Tracking** - Monitor your daily/weekly habit completion
- **Rewards System** - Earn rewards for consistency
- **Achievement System** - Unlock achievements based on your progress and streaks
- **Email Notifications** - Personalizable scheduled reminders sent to your email
- **Articles & Tips** - Browse helpful content for habit building
- **AI Chatbot** - GPT-powered assistant for personalized guidance
- **User Profiles** - Manage your account and preferences
